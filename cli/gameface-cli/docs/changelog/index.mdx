## 1.0.0 :badge[Latest]{variant="note"}

<Badge text="Feature" variant="success" size="small" /> Initial release of `gameface-cli`.

<Badge text="Feature" variant="success" size="small" /> `add <components...>` installs one or more components together with their transitive dependencies. Shared dependencies are downloaded once and `npm install` runs a single time, however many components are requested.

<Badge text="Feature" variant="success" size="small" /> `update [components...]` brings installed components to the current published version. With no arguments it sweeps everything tracked in `package.json`, leaving up-to-date components untouched.

<Badge text="Feature" variant="success" size="small" /> `status` lists installed components with their versions, flags the ones that have updates available, and reports how many more components the library offers.

<Badge text="Feature" variant="success" size="small" /> Installed components and their versions are recorded under `gameface-ui-components` in the project's `package.json`, preserving its existing indentation.

<Badge text="Feature" variant="success" size="small" /> `--yes` skips every confirmation prompt for non-interactive and CI use, and `--help` prints usage.

<Badge text="Feature" variant="success" size="small" /> Setup instructions are printed the first time components are installed into a project that has not used the CLI before.
