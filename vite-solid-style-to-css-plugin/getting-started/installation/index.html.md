# Installation

> Documentation index: https://frontend-tools.coherent-labs.com/llms.txt lists every page of this documentation as Markdown; the full text is in https://frontend-tools.coherent-labs.com/llms-full.txt.

Source: https://frontend-tools.coherent-labs.com/vite-solid-style-to-css-plugin/getting-started/installation/

To install the plugin in your project, run the following command:

```shell
npm install vite-solid-style-to-css --save-dev
```

**We recommend using Node.js version 20 or higher.**
