# Overview

> Documentation index: https://frontend-tools.coherent-labs.com/llms.txt lists every page of this documentation as Markdown; the full text is in https://frontend-tools.coherent-labs.com/llms-full.txt.

Source: https://frontend-tools.coherent-labs.com/e2e/api/gamefacegamepad/

The `GamefaceGamepad` object provides various methods to simulate gamepad interactions in your UI.

Creating such object is done through the `gf.connectGamepad` method.

Once you have connected a gamepad you can use the methods described in this section.
